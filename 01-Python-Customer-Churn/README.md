# Customer Churn Analysis

## Problem
A telecom company wants to understand why customers are leaving and how to reduce churn.

## Dataset
Telco Customer Churn Dataset — 7,043 customers, 21 features

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn

## Key Insights

| Factor | Finding |
|--------|---------|
| Overall Churn | 26.5% |
| Month-to-month contracts | 42.7% churn |
| Two-year contracts | 2.8% churn |
| New customers (0-12 months) | 47.4% churn |
| Fiber optic users | 41.9% churn |
| Electronic check payers | 45.3% churn |

## Files
- `notebook.ipynb` — full analysis with code and visualizations
- `images/` — charts

## How to Run
1. Install requirements: `pip install pandas numpy matplotlib seaborn`
2. Open `notebook.ipynb` in Jupyter
3. Run cells top to bottom
