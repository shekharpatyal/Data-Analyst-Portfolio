## Projects
# 1. Customer Churn Analysis (Python)
Analyzed 7,043 telecom customers to understand why they leave and how to retain them.

Key Findings:
- 26.5% overall churn rate
- Month-to-month contracts churn at 42.7% vs 2.8% for 2-year contracts
- New customers (0-12 months) have 47.4% churn rate
- Fiber optic users churn at 41.9%

Tools: Python, Pandas, Matplotlib, Seaborn

[View Project](./01-Python-Customer-Churn/)

## 2. Music Store Analysis (SQL)
Analyzed digital music store data using advanced SQL queries.

**Key Findings:**
- Rock genre accounts for 835 track sales
- Jane Peacock generates 35.77% of total sales
- Top customer: Helena Holý ($49.62 lifetime value)

**Concepts:** JOINs, CTEs, Window Functions (RANK, LAG, NTILE)
